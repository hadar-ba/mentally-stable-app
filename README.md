# Mentally-Stable-App  
Web-app built with a clean, data-driven UX and modular component architecture. Users navigate a home screen that offers cognitive-behavioural modules such as “Identifying Negative Thoughts” and “Success Journal”.

## 🚀 Features  
- Modular exercise cards (5-10 min sessions)  
- Library & Profile navigation tabs  
- Google OAuth2 Sign-In  
- Mobile-first responsive design  

## 🛠 Tech Stack  
React · TypeScript · Redux Toolkit · OAuth2 · Base44 platform

## 🧩 Installation  
1. Clone the repo: `git clone https://github.com/hadarmzr-spec/mentally-stable-app.git`  
2. `cd mentally-stable-app`  
3. `npm install`  
4. `npm start`
